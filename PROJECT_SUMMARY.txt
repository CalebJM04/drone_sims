Drone Awareness Mesh — Reduced Team Foundation

The project currently provides deterministic drone motion scenarios, a modeled
LoRa radio network, telemetry/CRC handling, basic multi-hop forwarding, neighbor
state tracking, collision prediction, and simulated avoidance. A single-node
service and core verification suite are available without hardware.

Three teammate features remain: predictive links/proactive routing, independent
node processes and mesh orchestration, and the live dashboard/mesh acceptance
report. See docs/TASK_1_ROUTING.md, docs/TASK_2_NODE_PROCESSES.md, and
docs/TASK_3_DASHBOARD.md. The current state is in docs/PROJECT_STATE.md.
