Drone Awareness Mesh Project Summary

The project is a software testbed for a resilient awareness network of simulated
drones. Independent companion processes share position and velocity over a LoRa
RF model, predict degrading links, select multi-hop relay paths before a direct
link breaks, and report collision risk. The main demo runs six node processes
with a live topology dashboard. Flight control is disabled.

The tests cover damaged packets, GPS errors, network failures, congestion,
restarts, and missing commands. The six-node configuration is the validated
target. Runs with 4 to 16 nodes are supported for scale experiments. Hardware,
radio-range, GNSS, airframe, and real-flight claims are outside the project scope.
